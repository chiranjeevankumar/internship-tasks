Personal Expense Tracker with CSV

Project 03 – Python Programming

Description

A Python application that records, stores, filters and summarizes personal expenses using CSV file handling.

Features

- Add daily expenses.
- View all recorded expenses.
- Filter expenses by category.
- Filter expenses by month.
- Calculate spending totals by category.
- Display grand total and biggest expense.
- Store expenses permanently in expenses.csv.
- Validate dates and expense amounts.

Technologies

- Python 3
- CSV module
- Datetime module
- Collections module

How to Run

1. Open project3.py in a Python editor.
2. Run the program.
3. Select an option from the menu.
4. Expenses are automatically saved in expenses.csv.

CSV Format

date,category,description,amount

Categories

Food, Travel, Study, Bills and Fun.

Conclusion

This project demonstrates Python functions, loops, CSV file handling, input validation and data summarization.
